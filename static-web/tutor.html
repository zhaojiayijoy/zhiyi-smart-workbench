老师，参照群体和意见领袖到底怎么区分？书上说意见领袖也属于参照群体，那为什么案例里要分开讲？
先想一想：如果一个人只是「被比较」，他会不会主动传播信息？把这两个动作分开，你就能找到区别了。
你的卡点在于把「所属关系」和「影响力来源」混在一起。参照群体强调比较与归属，意见领袖强调信息与说服。
1. 参照群体：个体用来比较或作为行为标准的群体，可以是所属群体，也可以是向往群体。
2. 意见领袖：在特定领域具有专业性或影响力、能改变他人态度的人，属于一种特殊的参照对象。
3. 关系：意见领袖是参照群体中的「高影响节点」；前者回答「跟谁比」，后者回答「听谁的」。
4. 案例中的应用：美妆博主的推荐（意见领袖）与同学都在用（参照群体）往往同时出现，需要分别说明作用机制。
