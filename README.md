# 致壹智能教育工作台

课程管理、教师备课、实训发布、学生作业提交、教师评审和学情分析。

## 安装与启动

建议使用 Python 3.11 或 3.12，在项目根目录执行：

```powershell
python -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
Copy-Item .env.example .env
```

编辑 `.env`，首次启动必须填写自己的 `EDU_TEACHER_PASS`（至少 12 位）；
教师用户名默认为 `teacher`。模型功能另需配置自己的服务密钥，演示预演不需要密钥。
不要把 `.env`、数据库、学生名单或作业提交到 Git。

```powershell
.\.venv\Scripts\python.exe api_server.py
```

浏览器访问 `http://127.0.0.1:8700/login.html`。
API 与静态页面由同一个服务托管，无需再启动静态服务器。
端口冲突时可在 `.env` 设置 `EDU_API_PORT=8701`，浏览器也使用相应端口。
如以前设置过浏览器本地的 `edu_api_base`，需清除或改为正确地址。

## 学生账号与权限

1. 教师创建课程，再为该课程导入含学号、姓名、班级的名单。
2. 学生使用学号登录，初始密码为学号后 6 位，首次登录强制改密。
3. 学生完善学籍信息，班级必须与教师导入的名单一致。
4. 学生只能访问名单中本人所属的课程，以及教师已发布、符合班级范围的任务。

权限以课程名单和学号为准，修改显示姓名或个人班级不会增加权限。
同名学生不会互相看到记录；旧数据中只有姓名、没有学号的评审和答疑默认不向学生显示，
需由教师核实归属后补齐 `meta.student_no`，不可按姓名盲目迁移。
学生端只返回任务摘要和已发布或已退回的本人反馈，不返回整份教师备课包或 AI 评审草稿。
学生作业仅教师可见，默认不参与通用 AI 上下文；学生仍可下载本人的提交历史。

## 课堂预演

- 正常预演使用当前课程的备课包；模型失败时会明确标记为演示结果。
- 快速体验使用独立演示入口，即使课程已有备课包，也不会调用模型。
- 双模型审核开关传递到后台，重新运行保留原设置；切换课程时清空旧结果并忽略过期响应。
- 真实预演的修补生成独立、未发布的备课草稿，保留原备课包。
- 修补内容作为带目标位置的补充要求加入教案准备项，并保留结构化修补记录，
  不自动重写评分权重或任意替换原文。教师应在备课历史查看、编辑并确认后发布。
- 重复应用不会重复追加；撤销会重建同一份草稿；已发布的草稿必须先撤回才能修改。
- 演示结果不能应用到真实备课包。

## 数据维护

重要数据位于 `.data/workbench.db`，课程导出文件还可能位于 `projects/`。
升级前停止服务，备份整个 `.data/`、`projects/` 和自己的 `.env`。
不要在生成任务运行期间执行数据重置，也不要多进程同时执行维护。

重置将删除课程、名单、资料、任务、预演、提交与提交版本，以及学生账号和会话；
保留教师账号与教师会话，不重置 ID 序列，防止旧引用与新记录碰撞。
重置不可恢复，请先备份。数据库重置本身不删除外部课程目录，必要时单独核对清理。

已有教师账号不会因为修改 `.env` 自动更换密码。
旧部署如曾使用公开的初始密码，必须单独修改现有账号密码，并使旧会话失效。

## 测试

安装项目依赖及测试客户端：

```powershell
python -m pip install -r requirements-dev.txt
python -m unittest discover -s tests -v
node --test tests/test_frontend.cjs
```

回归测试使用临时数据库，不读取现有业务数据库，也不调用付费模型。
模型响应由测试替身提供，覆盖权限隔离、发布过滤、零分、重置、作业版本及预演修补等流程。
前端测试覆盖接口凭证、端口、演示按钮、模型文本转义和课程切换，需要 Node.js 18+。
本次还使用真实浏览器检查了预演页面的登录态、演示生成、桌面/手机布局和课程切换。
真实模型质量、外部文件解析、并发压测和其余页面的完整浏览器交互仍需按部署环境验收。

## 部署边界

默认 API 仅监听本机。需要局域网访问时才设置 `EDU_API_HOST=0.0.0.0`，
并配置 HTTPS、访问控制、备份及登录限流；当前版本不应直接暴露公网。
Streamlit 是另一套教师工作台，**不经过 API 登录与角色权限控制**，
仅供本机或受信任网络使用，不能将它与带学生权限的 Web 站点一同公开。

```powershell
python -m streamlit run streamlit_app.py
```

Streamlit 默认只监听 `127.0.0.1:8501`。`run_service.ps1` 管理的是此 Streamlit 服务，
不是 Web/API 服务。生产环境还应补充任务队列、维护锁、审计记录、限流与依赖锁定。
