# 致壹智能教育工作台

课程管理、教师备课、实训发布、学生作业提交、教师评审和学情分析。

## 安装与启动

建议使用 Python 3.11 或 3.12，在项目根目录执行：

```powershell
python -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
Copy-Item .env.example .env
```

教师默认账号为 `teacher`，初始密码为 `Zhiyi@2026`；首次登录后请立即修改密码。
也可在 `.env` 中通过 `EDU_TEACHER_USER` 和 `EDU_TEACHER_PASS` 自行设置。模型功能另需配置自己的服务密钥，演示预演不需要密钥。
不要把 `.env`、数据库、学生名单或作业提交到 Git。

```powershell
.\.venv\Scripts\python.exe api_server.py
```

浏览器访问 `http://127.0.0.1:8700/login.html`。
API 与静态页面由同一个服务托管，无需再启动静态服务器。
端口冲突时可在 `.env` 设置 `EDU_API_PORT=8701`，浏览器也使用相应端口。
如以前设置过浏览器本地的 `edu_api_base`，需清除或改为正确地址。

## 学生账号与权限

1. 教师创建课程，再为该课程导入含学号、姓名、班级的名单。
2. 学生使用学号登录，初始密码为学号后 6 位（学号不足 6 位时使用完整学号），首次登录需修改密码。
3. 学生完善学籍信息，班级必须与教师导入的名单一致。
4. 学生只能访问名单中本人所属的课程，以及教师已发布、符合班级范围的任务。

权限以课程名单和学号为准，修改显示姓名或个人班级不会增加权限。
同名学生不会互相看到记录；旧数据中只有姓名、没有学号的评审和答疑默认不向学生显示，
需由教师核实归属后补齐 `meta.student_no`，不可按姓名盲目迁移。
学生端只返回任务摘要和已发布或已退回的本人反馈，不返回整份教师备课包或 AI 评审草稿。
学生作业仅教师可见，默认不参与通用 AI 上下文；学生仍可下载本人的提交历史。
已有账号再次导入名单不会覆盖密码；教师无需为学生单独创建或发放激活密码。
学生反馈和答疑按本人学号、课程及发布状态先筛选再分页，可在页面加载更多历史记录。
同一提交窗口对未更改内容的重试沿用请求标识，不重复生成版本或 AI 评审；更改文件或备注后视为新提交。
处理中的重试返回 409；服务意外中断导致提交长期未完成时，由教师核对后重新提交，不自动重试付费模型。

## 课堂预演

- 正常预演使用当前课程的备课包；模型失败时会明确标记为演示结果。
- 快速体验使用独立演示入口，即使课程已有备课包，也不会调用模型。
- 双模型审核开关传递到后台，重新运行保留原设置；切换课程时清空旧结果并忽略过期响应。
- 真实预演的修补生成独立、未发布的备课草稿，保留原备课包。
- 修补内容作为带目标位置的补充要求加入教案准备项，并保留结构化修补记录，
  不自动重写评分权重或任意替换原文。教师应在备课历史查看、编辑并确认后发布。
- 重复应用不会重复追加；撤销会重建同一份草稿；已发布的草稿必须先撤回才能修改。
- 演示结果不能应用到真实备课包。

## 数据维护

重要数据位于 `.data/workbench.db`，课程导出文件还可能位于 `projects/`。
升级前停止服务，备份整个 `.data/`、`projects/` 和自己的 `.env`。
不要在生成任务运行期间执行数据重置，也不要多进程同时执行维护。

重置将删除课程、名单、资料、任务、预演、提交与提交版本，以及学生账号和会话；
保留教师账号与教师会话，不重置 ID 序列，防止旧引用与新记录碰撞。
重置不可恢复，请先备份。数据库重置本身不删除外部课程目录，必要时单独核对清理。

已有教师账号不会因为修改 `.env` 自动更换密码。
升级时数据库会按版本迁移，不再在每次查询时执行建表和历史回填，连接使用后显式关闭。
旧部署中仍处于首次改密状态的学生会恢复为按学号生成的初始密码，旧会话也会失效。
已改过密码的学生及现有教师账号不受此迁移影响。
已有短密码不会强制失效，但后续修改统一要求 12–256 位。

### 备份与恢复

设置中的备份使用 SQLite 在线备份接口生成数据库快照并检查完整性，包含上传目录、导出目录、
`PROJECT_DIR` 及显式授权的 `BACKUP_EXTRA_DIRS`。课程指定的目录若未授权或已丢失，将拒绝备份，
避免生成表面成功但不完整的压缩包。遇到符号链接或目录联接也会拒绝，不跟随链接读取外部文件。
配置外部目录时只授权必要的课程文件夹，不要授权整个磁盘、用户目录或含 `.env`、密钥的目录。

压缩包含 `manifest.json`，记录原目录映射、文件大小与 SHA-256，便于恢复时核验。
数据库具有一致快照；外部文件仅逐个检查是否在复制中改变，不保证整个文件集的统一时间点。
正式备份前停止生成及文件写入任务；发现文件变化会中止备份。压缩包含学生隐私及登录会话，需受控保存。
常规备份不包含项目根目录的 `.env`，应单独安全保存配置。

恢复时停止服务，先将压缩包解压到隔离目录并核验清单中的文件哈希，再对 `workbench.db` 执行
`PRAGMA integrity_check`。保留现库副本后，将数据库放回 `.data/workbench.db`，按清单目录映射恢复文件，
跨机器恢复需调整课程目录路径和授权配置。首次启动前清空恢复库中的 `sessions`，要求所有账号重新登录。
先用测试环境确认课程、附件下载及提交历史可读取，再替换正式环境。

## 测试

安装项目依赖及测试客户端：

```powershell
python -m pip install -r requirements-dev.txt
python -m unittest discover -s tests -v
node --test tests/test_frontend.cjs
node --test tests/test_cursor.cjs
```

回归测试使用临时数据库，不读取现有业务数据库，也不调用付费模型。
模型响应由测试替身提供，覆盖权限隔离、发布过滤、零分、重置、作业版本及预演修补等流程。
前端测试覆盖接口凭证、端口、演示按钮、模型文本转义和课程切换，需要 Node.js 18+。
本次还使用真实浏览器检查了预演页面的登录态、演示生成、桌面/手机布局和课程切换。
真实模型质量、外部文件解析、并发压测和其余页面的完整浏览器交互仍需按部署环境验收。

## 部署边界

默认 API 仅监听本机。需要局域网访问时才设置 `EDU_API_HOST=0.0.0.0`，
并配置 HTTPS、访问控制及备份；当前版本不应直接暴露公网。
登录已按账号限制为每 15 分钟最多 8 次未成功尝试，成功后清除该账号计数；
按来源每 15 分钟最多 200 次尝试，兼顾学校共享出口。达到上限返回 429 和 Retry-After。
计数存入 SQLite，重启不会清空。接口不信任客户端伪造的转发地址；反向代理部署时，
应在受信网关补充真实来源限流，避免所有用户共用代理地址达到上限。
Streamlit 是另一套教师工作台，**不经过 API 登录与角色权限控制**，
仅供本机或受信任网络使用，不能将它与带学生权限的 Web 站点一同公开。

```powershell
python -m streamlit run streamlit_app.py
```

Streamlit 默认只监听 `127.0.0.1:8501`。`run_service.ps1` 管理的是此 Streamlit 服务，
不是 Web/API 服务。数据库迁移需在单进程启动或停机维护时完成。
生产环境还应补充任务队列、维护锁、审计记录、网关级保护与依赖锁定。

## 外观动效

鼠标跟随动效默认关闭，可在教师或学生外观设置中开启，保留原生指针及文本输入光标。
系统开启减少动效或设备不支持精细指针时自动禁用；鼠标静止、窗口失焦及后台页面不持续调度动画帧。
